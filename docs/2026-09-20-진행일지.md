# 2026-09-20 진행일지 (네이티브 Ubuntu 전환 및 LMDrive 첫 완주)

## 완료한 작업

### 1. Ubuntu 26.04.1 LTS 듀얼부팅 설치

WSL2의 GPU 렌더링 드라이버 미지원 문제를 해결하기 위해 네이티브 Ubuntu로 전환했다.

- 파티션: nvme0n1p6 (943GB, ext4)
- Windows(nvme0n1p3, NTFS 1.05TB)는 보존
- 설치 중 rsync 오류로 1차 실패 → ISO 재다운로드(26.04.1) 후 재설치 성공
- 서드파티 드라이버(NVIDIA) 및 미디어 코덱 포함 설치

### 2. GPU 렌더링 문제 해결 확인

WSL2에서 가장 큰 병목이었던 문제가 해결되었다.

WSL2: OpenGL renderer string: llvmpipe (LLVM 21.1.8, 256 bits)
네이티브: OpenGL renderer string: NVIDIA GeForce RTX 5070 Ti/PCIe/SSE2

### 3. 개발 환경 복원

Windows 파티션을 마운트하여 백업 데이터를 Ubuntu 파티션으로 이전했다.

- 백업 데이터 41GB 복사 (모델 가중치, CARLA, 수정 코드 일체)
- Miniconda 설치 및 conda 환경 복원
- environment_export.yml에서 로컬 설치 패키지(salesforce-lavis, timm) 및 torch 계열 제외 후 생성
- torch 2.8.0+cu128, torchvision 0.23.0+cu128 별도 설치
- torch_scatter 2.1.2+pt28cu128 설치
- vision_encoder(timm), LAVIS를 editable 모드로 설치
- numpy 1.24.4 + opencv-python-headless 4.5.5.64로 통일 (ABI 충돌 해결)

### 4. 카메라 렌더링 성능 검증

WSL2와 동일한 조건으로 재측정한 결과:

| 환경 | 카메라 20틱 소요시간 |
|---|---|
| WSL2 | 17.97초 |
| 네이티브 Ubuntu | 0.32초 |

55.5배 개선되었으며, 센서를 부착하지 않은 순수 tick 속도(0.32초)와 동일한 수치로 렌더링 오버헤드가 사실상 제거되었다.

### 5. 경로 및 코드 수정

- run_evaluation.sh, lmdriver_config.py의 경로를 /mnt/c/LMDrive에서 /home/gj/LMDrive로 변경
- pygame 시각화 비활성화 (CARLA와 OpenGL 컨텍스트 충돌로 Segmentation fault 발생)
- CARLA 실행 옵션에 -ResX=400 -ResY=300 -RenderOffScreen 추가

### 6. GPU 메모리 부족 문제 대응

네이티브 환경에서 CARLA가 GPU 렌더링을 정상 수행하게 되면서 새로운 문제가 발생했다.

- CARLA가 GPU 메모리 약 2.6~3.9GB 점유
- LMDrive 모델(LLaVA 7B)이 약 11GB 필요
- 총 15.46GB 중 여유 부족으로 CUDA OOM 발생

대응:
- LLM을 8bit 양자화하여 로드 (load_in_8bit=True, device_map={"": 0})
- bitsandbytes 설치
- PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True 환경변수 추가
- 시나리오 종료 시 GPU 메모리 명시적 해제 코드 추가 (gc.collect, torch.cuda.empty_cache)

### 7. 첫 시나리오 완주 성공

RouteScenario_0에서 최초로 정상 주행에 성공했다.

| 항목 | 결과 |
|---|---|
| RouteCompletionTest | SUCCESS (100%) |
| CollisionTest | SUCCESS (0회) |
| RunningRedLightTest | SUCCESS (0회) |
| RunningStopTest | SUCCESS (0회) |
| OutsideRouteLanesTest | FAILURE (0.8%) |
| Duration (Game Time) | 35.9초 |
| Duration (System Time) | 138.72초 |
| Ratio (System/Game) | 0.259 |

게임시간 35.9초를 실제 138초에 처리했다. WSL2 환경이었다면 약 6시간이 소요될 작업이다.

## 트러블슈팅 기록

| 문제 | 원인 | 해결 |
|---|---|---|
| Ubuntu 설치 중 rsync 오류 | ISO 파일 손상 추정 | 26.04.1 버전으로 재다운로드 |
| conda env create 실패 | 로컬 설치 패키지(salesforce-lavis, timm)가 PyPI에 없음 | 해당 항목 제외 후 editable 설치 |
| torch 2.8.0+cu128 설치 실패 | PyPI에 CUDA 빌드 없음 | PyTorch 공식 index-url 사용 |
| libtorch_cuda.so undefined symbol ncclMemFree | 구버전 nvidia-nccl-cu11 잔존 | cu11 패키지 제거 후 torch 강제 재설치 |
| numpy ABI 충돌 | numpy 2.x와 opencv 불일치 | numpy 1.24.4 + opencv-headless 4.5.5.64 |
| pygame Segmentation fault | CARLA와 OpenGL 컨텍스트 충돌 | 시각화 비활성화 |
| CUDA OOM | CARLA와 모델이 GPU 메모리 경합 | 8bit 양자화 + 메모리 정리 코드 |
| dtype 불일치 (Float vs Half) | half() 적용과 입력 데이터 타입 불일치 | half() 제거 |
