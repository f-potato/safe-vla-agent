## 트러블슈팅 기록

| 문제 | 원인 | 해결 |
|------|------|------|
| global_route_planner_dao 모듈 없음 | CARLA 0.9.13부터 삭제됨 | GlobalRoutePlanner 직접 사용으로 수정 |
| CUDA no kernel image | RTX 5070 Ti sm_120 미지원 | torch 2.8.0+cu128로 업그레이드 |
| torch_scatter 빌드 실패 | torch 버전 불일치 | PyG wheel 재설치 |
| torch.load 에러 | torch 2.6+에서 weights_only 기본값 변경 | weights_only=False 명시 |
| CARLA 맵 불일치 | load_world() 크래시 | CARLA 실행 시 -carla-world=Town01 지정 |
| LiDAR 포인트 배열 오류 | CARLA 0.9.15에서 포인트 수 증가 | 랜덤 샘플링으로 40,000개 선택 |
| 센서 타임아웃 | frame_rate 2Hz로 낮추면서 tick 지연 | 타임아웃 60초로 증가, frame_rate 원복 |
| Windows 줄바꿈 문제 | \r\n으로 인한 bash 스크립트 오류 | sed -i s/\r// 로 제거 |

## 교수님께 문의 예정 사항

1. CARLA 0.9.10.1 → 0.9.15 버전 변경으로 인한 베이스라인 비교 방법
2. torch 2.0.1 → 2.8.0 버전 변경이 실험 결과에 미치는 영향
3. LiDAR 포인트 랜덤 샘플링 유지 vs 고정 기준 선택
4. frame_rate 변경이 베이스라인 수치 신뢰성에 미치는 영향
5. 학습 시간 문제로 인한 GPU 서버 사용 가능 여부
